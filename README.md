# UpTax for Windows

Official Windows x64 installers and automatic updates for the UpTax desktop app.

Download the installer from [Releases](https://github.com/uptaxai/uptax-desktop-releases/releases).
Install it, then open UpTax. Sign in to your UpTax account as usual.

Update-enabled versions check for a newer release when the app opens. Choose
**Download update**, then **Install and reopen** when ready. You can select
**Later**, or check manually using **Help > Check for updates**.

If you are using version 0.2.7 or earlier, install an update-enabled version
manually once. Existing older builds do not check this release channel.

This repository contains distribution files only. It contains no application
source, tax returns, customer records, or credentials.
